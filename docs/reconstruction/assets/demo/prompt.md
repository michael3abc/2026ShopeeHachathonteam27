本文件可直接貼給 ChatGPT-Image。每案先貼共同規格與該案設定，再依序貼四個圖片 prompt；每次只生成一張。請把已生成的該案圖片當參考圖，維持同一件商品、裂痕、包裝與桌面。A/B/C 使用不同商品，不共用參考圖。

## 共同規格

生成供退款系統 Demo 使用的合成商品照片，寫實手機拍攝風格、自然室內光線、4:3 橫向、清晰但不過度修圖。無品牌 logo、真實人臉、姓名、住址、電話、物流商單據或支付資訊。每張右下保留清楚可讀的 `DEMO / AI-GENERATED` 標示，不加時間戳、不模擬真實送達證明。可呈現手部，但每案手部與桌面保持一致。損壞僅為指定局部裂痕，不增添冒煙、起火、漏液、裸露電池或其他未描述的損壞。不能由畫面推定完全無法修復或可正常運作。

每案共四張，對應 closeup、package、identity、arrival。最後一張是四格連續情境拼圖，不是真實連拍證據。標籤字樣若生成錯誤，請人工修正後核對，不修改商品事實來遷就錯圖。
